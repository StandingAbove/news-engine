# Installed on top of the core `requirements.txt`:
#
#   pip install -r requirements.txt
#   pip install -r requirements-forecast.txt
#
# This file does NOT include `timesfm`. That's because the `timesfm` PyPI
# package has an upper bound of Python <3.12, so `pip install timesfm` fails
# outright on Python 3.13. See the separate install step at the bottom of
# this file / in docs/FORECAST.md.

# --- Classical baselines (ARIMA, Holt-Winters) ---
statsmodels>=0.14,<1

# --- Neural baselines (MLP, LSTM) ---
# CPU-only wheels are plenty for a ~thousand-point series; install the CUDA
# build yourself if you have a GPU.
torch>=2.1,<3


# -----------------------------------------------------------------------------
# TimesFM — install separately. Pick ONE of the three paths below.
#
# (A) Python ≤3.12 (recommended): standard PyPI install.
#         pip install "timesfm>=1.2"
#
# (B) Python 3.13: install from source.
#     The main branch drops the <3.12 cap. Needs git-lfs installed locally:
#         brew install git-lfs && git lfs install
#         pip install "git+https://github.com/google-research/timesfm.git@main"
#     If you can't install git-lfs (locked-down machine), clone with LFS
#     skipped — the LFS files are just artifacts, not the Python package:
#         GIT_LFS_SKIP_SMUDGE=1 git clone https://github.com/google-research/timesfm.git /tmp/timesfm
#         pip install /tmp/timesfm
#     The HuggingFace download at model-load time still supplies the weights.
#
# (C) Python 3.13, if (B) fails: create a parallel venv pinned to 3.12
#     just for the forecasting sub-component. The text-feed sub-component and
#     the v2 stack keep using 3.13. The eval script can live on either side.
#         python3.12 -m venv .venv-forecast
#         source .venv-forecast/bin/activate
#         pip install -r requirements.txt -r requirements-forecast.txt
#         pip install "timesfm>=1.2"
#
# If none of (A)/(B)/(C) is available, the `TimesFMForecaster` class reports
# `is_available() == False` and the harness skips it cleanly — the other 8
# models still run.
# -----------------------------------------------------------------------------
